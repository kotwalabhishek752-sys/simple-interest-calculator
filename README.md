# simple-interest-calculator
# Simple Interest Calculator

A simple, lightweight script/application that calculates simple interest based on the principal amount, annual interest rate, and time period in years.

## Overview

Simple interest is calculated using the formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (in percentage)
- **T** = Time period (in years)

## Features

- Quick calculation of total simple interest earned or owed.
- Computes total final amount ($\text{Principal} + \text{Interest}$).
- Easy-to-read output format.

## Input Parameters

1. **Principal Amount**: The initial sum of money invested or borrowed.
2. **Rate of Interest**: The annual interest rate percentage.
3. **Time Period**: The time duration in years.

## Usage

1. Clone or download this repository.
2. Run the simple interest calculator script using your environment (e.g., Python, JavaScript, or Bash script).
3. Enter the required values when prompted.

## Example

- **Principal ($P$)**: $1000
- **Rate ($R$)**: 5%
- **Time ($T$)**: 2 years
- **Calculated Interest**: $100
- **Total Amount**: $1100
